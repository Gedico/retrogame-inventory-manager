# 📦 RetroGame Inventory Manager — Full-Stack Web App

Web App Full-Stack sviluppata per ottimizzare la gestione dell'inventario, il calcolo dei margini di profitto e il tracciamento del valore di mercato di videogiochi e console usate.

---

### 🏛️ Struttura del Progetto (Monorepo)

- 🎨 **`/frontend`**: Interfaccia utente reattiva (Dashboard visiva, gestione tabelle, grafici di andamento).
- ⚙️ **`/backend`**: Servizio Backend API REST, gestione database relazionale e integrazione con API esterne (IGDB / RAWG).

---

### 🚀 Funzionalità Previste

- **Gestione Inventario:** Inserimento prodotti, costo di acquisto, prezzo di vendita stimato e reale.
- **Calcolo Margini & ROI:** Dashboard analitica per monitorare il capitale investito e il profitto netto.
- **Integrazione API IGDB:** Recupero automatico di copertine, anno e metadati ufficiali dei giochi.
- **Filtri & Ricerca:** Organizzazione rapida dell'inventario per piattaforma, stato di conservazione e disponibilità.

---

### 🛠️ Tech Stack (In Sviluppo)

- **Frontend:** React / JavaScript (o TypeScript)
- **Backend:** Node.js / Python (FastAPI / Express)
- **Database:** PostgreSQL / SQLite
- **API Esterne:** IGDB API / RAWG API
